              Home Assistant Connection

              Find these in your Home Assistant instance under Settings → About (URL) and Settings → Security → Long-Lived Access Tokens. This is shared with everyone signed in to this dashboard.

              Google Calendar Sync

              Two-way sync with a shared Google Calendar: events added here appear on that calendar, and events already on it (work events, vacations, birthdays, etc.) appear here too. Connecting is per-device and needs to be done once on each phone/computer you use.

              Gmail Invite Detection

              Optional and separate from Calendar sync above. When connected, Home Manager scans your Gmail for formal calendar invitations (emails containing a .ics invite file) and automatically adds them to your shared calendar. This grants read access to your whole Gmail inbox at the permission level — the app only looks at messages with calendar invite attachments and never stores or sends email content anywhere, but the access you grant is broader than what the app actually uses. Only connect this if you're comfortable with that. It only scans whichever Gmail account you connect with, on this device — each person connects separately for their own inbox to be scanned.

              Data

              All data is stored in a shared Firebase database and synced live to everyone signed in.
